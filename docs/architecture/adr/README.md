# Architecture decision records (§1.4)

Changing a decision from the AI Specification v1.1: add `NNNN-short-title.md` here naming the
decision ID (e.g. A-25, S-11) and its impact. The AI lead and product owner approve; shared
decisions (S-xx, Appendix A/B) also need the Platform lead. Prompt/model changes also need a
passing evaluation report (A-30).

Template:

```
# NNNN: <title>
- Decision ID: <S-xx / A-xx>
- Status: proposed | accepted | superseded
- Context: what the spec says and why it needs changing
- Decision:
- Impact: contracts, services, evaluation
- Approvals: AI lead, product owner[, Platform lead]
```

Open items to raise here once both leads review them: `contracts/ASSUMPTIONS.md`.
